# PayGuard editable source kit

These are **newly reconstructed, editable SVG vectors**, inspired by the selected raster brand board. They are not the original layered AI/Figma files; the mascot illustration is not reconstructed here.

Open SVG files in Figma, Adobe Illustrator, Inkscape, or a browser. All vector paths are editable. Wordmark remains editable text and may look different if your font differs; convert text to outlines after selecting a font.

Contents: primary logo, symbol, monochrome, horizontal, light/dark app icons, four feature icons, and color tokens.
