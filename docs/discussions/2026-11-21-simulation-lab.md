# Simulation Lab implementation request

The project owner asked for the Simulation Lab from the Git and Google Drive documentation, using Next.js, Tailwind CSS, Go, Redis and PostgreSQL, with documentation updated.

- The Drive package defines a seeded storefront-to-QA flow. The [System Handbook](https://docs.google.com/document/d/1RtzQI1VIRXabDKUBPGcfQM8NxJZs1u_geFWFYC8Hq_I/edit) describes a separate earlier numeric MVP, and the checked-out repository started with project notes only.
- This delivery implements two synthetic storefronts and the scoped evidence/QA loop. See the [requirements](../requirements/simulation-lab.md) and [UI](../ui/simulation-lab.md).
- Mock Jev, the fixed demonstration domain and the compact run schema are local implementation decisions. See [storage and evidence](../decisions/2026-11-21-simulation-storage.md) for rationale and [current work](../current-work.md) for verification.
